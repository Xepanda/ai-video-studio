# Science Pop Explainer Video Production (科普实证与方法论解说视频制作体系)

## Overview

本技能沉淀自制作《高性价比人生指南》等高质量科学实证、医学健康与开源生活指南视频的完整生产经验。

**核心痛点与行业反模式：**
1. **暗黑深色压抑**：照搬程序员黑客深色终端（`#090d16`），在科普、健康与生活选题下极其沉闷刺眼，大幅推高用户认知负荷与跳出率；
2. **PPT 式流水账**：纯文字提纲罗列或单调代码滚动，毫无视觉说服力与视听节奏；
3. **生硬直入缺乏共鸣**：开头直奔“第几章第几条”，忽视普通观众对痛点和情绪共振的需求；
4. **劣质转场噪音**：机械刷刷声、激光扫频等科技转场音效频繁切断叙事沉浸感；
5. **证据链薄弱**：仅有空洞口播，缺乏权威文献、代码仓库、官方数据的真实可视证明。

本技能确立了**“温润纸感美学 + 拟真视窗证据链 + 共鸣式双层钩子 + 纯净人声母带”**的现代化工业制作范式。

## 1. 经典五段式科学实证叙事法则 (5-Stage Scientific Narrative Architecture)

```
[1. 现实痛点与情绪共鸣] ➔ [2. 破局点题与确定性收益] ➔ [3. 循证医学与工程实证] ➔ [4. 极高杠杆动作拆解] ➔ [5. 决策自查与闭环沉淀]
```

### 1.1 第 1 幕：现实痛点与情绪共鸣 (Empathy & Crisis Hook)
- **绝对禁忌**：严禁开场直接背书名或读第一章标题（如“今天我们读高性价比人生指南第一章”）。
- **叙事方法**：直击观众日常生活、健康焦虑或生存痛点，建立“努力与风险归零”的危机预期。
- **经典句式**：
  > “大家平时都在拼命搞钱、内卷升职，但你有没有想过，如果最底层的健康和安全出了问题，前头的所有努力都会瞬间归零？”

### 1.2 第 2 幕：破局点题与确定性收益 (The Paradigm Shift)
- **叙事方法**：引出被广泛验证的解决方案或开源宝藏神作，强调“投入极小成本，换取确定性收益”。
- **视觉配合**：切入真实 GitHub 仓库视窗或官方主页（`WebBrowserMockupScene`），展示 Star 数、贡献者以及实证标准体系。
- **经典句式**：
  > “今天我们来讲：开源神作《高性价比人生指南》。这份指南不同于市面上的廉价鸡汤，它的每一条建议都必须跨过严苛的循证医学门槛……”

### 1.3 第 3 幕：循证医学与权威期刊实证 (Evidence & Data Rigor)
- **叙事方法**：用大样本前瞻性随机对照临床试验（RCT）或顶刊论文打消质疑，用数据说话。
- **视觉配合**：展示权威医学期刊视窗（如 NEJM、Lancet），高亮样本规模（如 20,995 人）与关键降幅（如中风发病率降 14%、全因死亡率降 12%）。
- **经典句式**：
  > “《新英格兰医学杂志》跟踪两万多名老人近五年发现：仅仅是在买盐时换成含钾低钠盐，全因死亡率就能直降 12%，脑卒中发病率直降 14%。”

### 1.4 第 4 幕：极高杠杆动作拆解 (High-Leverage Action Bento)
- **叙事方法**：拒绝复杂宏大的说教，只给“改动极小、成本极低、终身受益”的确定性动作。
- **视觉配合**：Bento 矩阵卡片式对比（如普通食盐 vs 低钠替代盐配方对比；几十元独立式光电烟雾报警器 ROI 分析）。
- **经典句式**：
  > “不需要你每天跑十公里或者戒掉所有碳水，只要把厨房里几块钱的普通钠盐换成含钾低钠替代盐，就能获得近乎确定性的健康红利。”

### 1.5 第 5 幕：决策自查与闭环沉淀 (Self-Audit & Call To Action)
- **叙事方法**：提供落地检查清单，建立长期跟踪或下一期期待。
- **视觉配合**：展示交互自查手册截图，底部列出实证级别标签与行动口号。

## 2. 浅色纸质典雅美学系统 (`editorial-paper-light`)

### 2.1 调色板与材质规范
科普与健康视频严禁使用纯黑背景（`#000000` 或 `#090d16`），应采用温润如纸的浅色典雅体系：

| 属性 | 变量值 | 视觉感知与用途 |
|---|---|---|
| **纸底底色** | `#faf7f0` ~ `#f4ede2` | 雅致书籍、报刊微暖米白，护眼防眩光 |
| **卡片/视窗背景** | `#ffffff` (纯白 + 柔和投影) | 层次分明，具有现代物理实体卡片感 |
| **主要文字** | `#1e293b` (深石墨黑) | 极佳对比度（WCAG AAA 级），字迹沉稳 |
| **次要文字** | `#64748b` (中灰) | 辅助说明、副标题、标签 |
| **实证强调色** | `#0284c7` (科学蓝) / `#10b981` (健康翡翠绿) | 核心指标、百分比、重点数据胶囊 |
| **预警提示色** | `#f59e0b` (暖琥珀) / `#ef4444` (警示红) | 痛点、事故率、死亡率等警示数据 |

### 2.2 样式排查硬指标
1. **消除 Root 硬编码背景**：检查 `src/Root.tsx` 中的 `<AbsoluteFill>`，确保背景色取自 `theme.background`，不得硬编码 `#090d16`。
2. **禁用 70% 边缘暗角**：在 `ProceduralBackground.tsx` 中，浅色模式下不得叠加高不透明度的 dark vignette，否则米白底色四周会呈现脏污暗灰色。

## 3. 多模态实证组件体系 (Evidence-Driven Components)

### 3.1 拟真浏览器视窗组件 (`WebBrowserMockupScene.tsx`)
用于呈现真实 GitHub 仓库、学术期刊、官方交互文档与权威资讯：
- **macOS 视窗结构**：左上方标配红黄绿拟真微圆形控制按钮，带柔和白底与 `0 24px 60px rgba(0,0,0,0.08)` 漫反射投影；
- **安全锁真实 URL 地址栏**：显示如 `github.com/eternity4719/HowToLiveBetter` 或 `nejm.org/doi/full/...`，极大增强可信度；
- **运镜微推缓动**：配合 Remotion 的 `spring` 或 `interpolate`，视窗图片进行 1.00 ➔ 1.04 的慢速推镜，杜绝静止死板；
- **底部实证悬浮胶囊**：展示“收录建议 690+ 条实证”、“临床样本 20,995 人”等核心量化筹码。

### 3.2 实证数据 Bento 对比组件 (`TechNewsShortsScene.tsx` / `UniversalScene.tsx`)
- **双栏/多栏对决卡片**：
  - 左卡（传统做法/高危项）：淡红/淡灰底，标注潜在危害；
  - 右卡（高杠杆实证解法）：薄荷绿/天蓝底，标注确凿收益。
- **数据翻牌/大数字指示**：核心降幅采用 `48px~64px` 超大加粗字体（如 `-14%`），配合清晰中文说明。

### 3.3 浮动式微光 Dock 逐字大字幕 (`DynamicSubtitles.tsx`)
- 横屏画幅居中靠下，底板为半透明纯白/微暖白磨砂玻璃（`rgba(255, 255, 255, 0.95)`），边缘附带轻微描边与微投影；
- 采用深石墨黑字体，当前发音词根据 SenseVoice 毫秒时间轴跳跃微放大或高亮为品牌蓝。

## 4. 自动化工具链 (Toolchain Automation)

### 4.1 Playwright 证据链截图自动化 (`scripts/generate_evidence_screenshots.py`)
用于从本地或线上环境自动化抓取无水印、超清真实网页/文档截图：
```bash
# 生成预设全部截图 (GitHub 仓库、NEJM 临床论文)
python scripts/generate_evidence_screenshots.py --preset all

# 截取任意线上/本地 URL (如本地运行的 Web 服务或在线文章)
python scripts/generate_evidence_screenshots.py --url "http://localhost:3000" --out public/images/my_demo.png --width 1920 --height 1080

# 将本地定制的高精度 HTML 模板渲染为 1080p 高清视窗图
python scripts/generate_evidence_screenshots.py --html "inputs/custom_evidence.html" --out public/images/evidence_custom.png
```

### 4.2 X/Twitter 动态热点与多模态素材抓取 (`scripts/x_fetcher.py`)
```bash
# 抓取指定权威推文 (自动下载作者蓝V头像、推文图片/视频并生成分镜 JSON)
python scripts/x_fetcher.py --url "https://x.com/WHO/status/..."
```

### 4.3 纯净商业音频母带处理 (`scripts/audio_mastering.py`)
- **音效清理**：剔除画面切换时的科技音效，保持叙事专注。
- **两遍双轨 EBU R128 标准化**（响度目标由 `scripts/audio_mastering.py` 的 `PLATFORM_LOUDNESS_PRESETS` 单一事实源裁决）：
  ```bash
  # 默认 web 预设（YouTube / B站 / 小红书）：-14.0 LUFS / TP ≤ -1.5 dBTP
  python scripts/audio_mastering.py --video out/how_to_live_better_ep01_horizontal.mp4 --platform web
  # 发布抖音 / 快手 / Reels 时切换短视频预设（-11.0 LUFS / TP ≤ -1.5 dBTP）：
  # python scripts/audio_mastering.py --video out/how_to_live_better_ep01_horizontal.mp4 --platform short_video
  ```
  - `120Hz` 四阶 Butterworth 高通滤波：切除扬声器次声波轰鸣；
  - `3.2kHz` 齿音微提升：保证小音量下咬字清晰；
  - 动态软压缩与软膝限制：杜绝爆音与电平过载。

## 5. 生产排查与反模式 Checklist

| 检查项 | 致命反模式 (RED) | 正确工程实践 (GREEN) |
|---|---|---|
| **背景色调** | `#090d16` 黑客暗黑底，四周带重度黑边 | `editorial-paper-light` 浅暖纸底，四周透亮温润 |
| **开场台词** | “今天我们来读第一章，第一节是关于买盐……” | 从“搞钱内卷、健康归零”的生活痛点切入，引发共鸣再点题 |
| **画面呈现** | 全片只有几行居中 PPT 文字或者一段终端代码 | 调取真实 GitHub 仓库、学术期刊论文、Bento 对比视窗 |
| **声音质感** | 每次镜头切换都响一下激光科技音效，音量忽大忽小 | 移除切换杂音；音频跑 EBU R128 母带，响度按发布平台取值（默认 web -14.0 LUFS / 短视频 -11.0 LUFS，TP ≤ -1.5 dBTP） |
| **素材引用** | 引用外链图片未加 try-catch 导致 Remotion 404 挂掉 | 本地生成或下载至 `public/images/`，使用 `staticFile(...)` 渲染 |
| **画幅选择** | 强行套用竖屏短视频模板导致代码/表格截断 | 科普深度解析统一采用 **16:9 横屏**（1920×1080）原生分辨率 |
