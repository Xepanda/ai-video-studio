# 抖音直播带货与实拍短视频全流程 SOP (Live E-Commerce Short Video SOP)

本 SOP 归档自实战带货短视频项目（以 63.8 秒新雪丽小棉服为例），定义了从几小时原始直播录像到高完播、高转化 45~65 秒短视频的标准作业规程。

---

## 阶段一：本地视频工程初始化
1. 本地视频工程统一存放在 `D:\dy-video-projects\` 下（不入 Git 仓库，避免污染代码库）；
2. 复制 `D:\dy-video-projects\_template_project\` 为新项目（如 `project1_jacket`）；
3. 将原始录像放入 `01_raw_materials/video/`。

---

## 阶段二：Faster-Whisper 毫秒级语音转录与台词时间戳定位
运行 ASR 提取全量词级/句级时间戳：
```bash
python scripts/live_ecommerce_pipeline.py --project "D:/dy-video-projects/project1_jacket" --transcribe
```
输出产物存放在 `02_scripts_and_docs/whisper_segments.json`。

---

## 阶段三：黄金 3 秒法则（Golden 3s Rule）重组
1. **打破线性时间顺序**：
   - 提取整场最极端、最煽动的重音金句（“别的棉服都被它比下去！”、“生日专场只排这一个！”）强行剪切到 0.0s~2.5s；
2. **超大视觉大标避障法则**：
   - 生成 980px 宽度大红金字大标，坐标严格锁定在 `y = 150 ~ 430`（覆盖背景招牌，且绝不压住模特脸部与眼神）；
3. **音频重音冲击波**：
   - 0.0s 混入算法合成的 45Hz~90Hz 带阻尼衰减 Sub-Bass Boom 冲击音效。

---

## 阶段四：镜头语言与分屏特效
1. **推镜特写（Detail Punch Zoom）**：
   - 在讲解 3M 新雪丽材质、可拆卸连帽、下摆立体捏褶处，应用 1.3× 变焦特写；
2. **镜像翻转（`hflip`）防反遮罩**：
   - 翻转画面时，必须使用营销卖点贴纸或标题精确覆盖背景镜像反字；
3. **对称双色真实对比（Symmetrical Split Comparison）**：
   - 左右 50:50 等比分屏（各 540x1920），左右模特身材等大且**均为穿上身的真实上身效果**（左藏青 vs 右米白），中间贯穿发光分割线。

---

## 阶段五：同步发光字幕与整片压制
1. 编写 `.ass` 动态字幕，核心利益点（面料、价格、版型）亮黄色突出；
2. 字幕垂直边距设为 `MarginV=240`，彻底避开抖音底部小黄车与账号描述；
3. 输出 1080x1920 60FPS 最终成片至 `04_final_output/`。

---

## 阶段六：爆款高转化率封面矩阵
1. 提取模特神态自然的**纯净无字正帧**；
2. 优先采用 **Option 1 爆款大促促销型封面**（金红主标 + 底部 300+ 价格腰封 + 原生实心五角星 `★` 排版，避免乱码方框）；
3. 产出封面保存至 `04_final_output/cover_default.jpg`。
